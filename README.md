## ✨ Основные возможности (Key Features)

### 📺 1. Телеканалы и Плейлисты (Live TV)
- Полная поддержка плейлистов **M3U / M3U8** (HLS, MPEG-TS, MP4, MKV).
- Добавление **нескольких именованных плейлистов** с быстрым переключением через выпадающее меню прямо над списком каналов.
- **Умная категория «⭐ Избранное»:** автоматически появляется в полоске категорий плейлиста, когда вы отмечаете звездочкой хотя бы один канал.
- **Быстрый возврат (Recall):** мгновенное переключение на предыдущий просмотренный канал.
- **Умный реконнект (Anti-Freeze):** автоматическое переподключение плеера Media3 при кратковременных обрывах потока.

### 🎬 2. Интерактивный Кинозал (VPortal & Stalker Portal)
- Нативная поддержка протокола **VPortal (`POST JSON`)** по ссылкам вида `portal::[key:...]http://.../api/v1/` (TVlider / iLook TV и аналоги).
- Полноценная навигация по папкам, категориям, сериалам, сезонам и сериям + встроенный поиск по базе видеопортала.
- **Бесконечная лента (Infinite Scroll):** автоматическая фоновая подгрузка следующих 50 фильмов при прокрутке списка до конца.
- Поддержка **Stalker Portal / Ministra** с авторизацией по MAC-адресу.

### 📅 3. Телепрограмма (EPG)
- Автоматическое извлечение ссылки на телепрограмму (`url-tvg` / `x-tvg-url`) прямо из активного M3U-плейлиста.
- Возможность добавлять несколько собственных источников EPG (`.xml` и сжатые `.xml.gz`) с выбором через выпадающее меню.
- Наглядная полоска загрузки и строка статуса обновления EPG в Настройках.

### 🎨 4. Дизайн и 10 цветовых тем (5 Тёмных + 5 Светлых)
- **5 Тёмных тем:** *Графит и Изумруд*, *Королевский Аметист*, *Кинозал Рубин*, *Глубокий Океан*, *Тёплый Мокко*.
- **5 Светлых тем:** *Скандинавское Утро*, *Тёплый Латте*, *Мятный Сад*, *Сакура и Роза*, *Лавандовый Кварц*.
- **2 языка интерфейса:** Русский 🇷🇺 и English 🇬🇧.
- Удобное меню настроек с разворачивающимися строчками («гармошка»).

### 📱 5. Умный QR-Пульт, Бэкап и Автообновление
- **QR-Пульт для ТВ:** отсканируйте QR-код с экрана телевизора камерой смартфона, чтобы отправить ссылки на плейлисты, EPG и VPortal по домашнему Wi-Fi без пульта.
- **Импорт и Экспорт настроек:** сохранение всех плейлистов, порталов, избранного и темы оформления в файл `CCTV-Plus-Backup.json` или через буфер обмена.
- **Встроенный Чейнжлог (Changelog):** история всех изменений прямо внутри приложения.
- **Автообновление с GitHub:** проверка, скачивание (с полоской прогресса `0%–100%`) и установка свежих версий поверх текущей без потери настроек.

## 🛠 Технический стек (Tech Stack)

- **Язык:** Kotlin + Coroutines
- **UI:** Jetpack Compose (Material 3)
- **Видеодвижок:** AndroidX Media3 (ExoPlayer + HLS + DASH)
- **CI/CD:** GitHub Actions (Автоматическая сборка подписанных Release APK V1+V2)
