## ✨ Ключевые возможности (Features)

### 📺 1. Прямой эфир и ТВ-навигация (Live TV & Remote Control)
- **Всеядность плейлистов:** поддержка `M3U` и `M3U8` (HLS, MPEG-TS), возможность хранить несколько плейлистов и загружать локальные файлы `.m3u` с памяти телефона или USB-флешки.
- **Умное «⭐ Избранное»:** категория появляется динамически только тогда, когда в списке есть отмеченные каналы.
- **Редактор категорий (`👁`):** скрывайте ненужные группы каналов одним касанием прямо с главного экрана.
- **Управление пультом ДУ (D-Pad):**
  - Стрелки `Вверх / Вниз` (`CH+ / CH-`) — мгновенный zapping (переключение каналов) в полном экране.
  - Кнопки `0–9` — прямой набор номера канала с красивым цифровым индикатором.
  - Кнопки `ОК` или `Влево` — вызов интерактивного ТВ-Гида.
- **Прозрачный 3-колоночный ТВ-Гид (стиль TiviMate):** выезжает прямо поверх идущего видео без остановки потока (`Категории ➔ Каналы ➔ Программа и Архив`).
- **Мультиэкран (Multi-View):** одновременный просмотр **до 4 каналов** на одном экране с переключением звука в один клик.

### 🎬 2. Кинозал VOD (VPortal & Stalker)
- **Нативный VPortal (`POST JSON`):** прямая работа со ссылками вида `portal::[key:...]http://.../api/v1/` (TVlider / iLook TV).
- **Бесконечная лента:** автоматическая подгрузка следующих 50 фильмов при прокрутке каталога до конца.
- **Карточка фильма:** постер, год, рейтинг, жанр и полное описание сюжета перед запуском.
- **Продолжить просмотр (Resume):** плеер автоматически запоминает точную секунду остановки и выводит удобную полосу недавних фильмов.
- **Stalker Portal / Ministra:** авторизация по MAC-адресу, автоматическое разрешение временных ссылок `create_link` и встроенная видеотека.

### 📅 3. Телепрограмма (EPG), Архив и Напоминания
- **Встроенные базы EPG:** пресеты *TVLider / Edem (`epg.it999.ru`)* и *IPTVx.one (Lite / Full)* прямо в выпадающем списке + кэширование на 6 часов для мгновенного старта.
- **Сдвиг времени EPG:** точная подстройка часового пояса от `-12` до `+12` часов.
- **Архив передач (Catch-Up):** глубина архива на **1, 3 или 5 дней**, плавная шкала прогресса эфира (без дерганий) и таймлайн перемотки архивных записей с шагом `±10 сек`.
- **Напоминания (`🔔`):** возможность отметить будущую передачу — приложение уведомит о начале и предложит переключить канал.

### 🎥 4. Профессиональный Видеоплеер
- **3 движка на выбор:**
  1. *Встроенный ExoPlayer (Media3)* — основной плеер с поддержкой ТВ-гида, 4 экранов и жестов.
  2. *Системный плеер Android (VideoView)* — легковесный движок для специфических потоков.
  3. *Внешний плеер* — запуск в один клик через VLC, MX Player, Vimu или Just Player.
- **Встроенный декодер FFmpeg:** аппаратное и программное декодирование звуковых дорожек `AC3`, `EAC3` и `DTS`.
- **Свайпы на смартфонах:** регулировка яркости по левому краю и громкости по правому краю экрана.
- **Мини-часы:** аккуратные часы реального времени прямо в плеере (`Слева / Справа / Выкл`).
- **Утилиты плеера:** режим «Картинка в картинке» (**PiP**), выбор звуковых дорожек, индикатор качества (`4K / 1080p • 50fps`), изменение скорости (`1.0x – 2.0x`) и **Таймер сна** (`15 – 90 мин`).

### 🎨 5. Дизайн, Безопасность и Утилиты
- **Мастер первого запуска:** выбор языка (RU/EN), типа устройства (Смартфон/ТВ) и управления (Сенсор/Пульт).
- **10 сбалансированных тем:** 5 тёмных (*Графит и Изумруд, Королевский Аметист, Полночный Сапфир, Бархатный Рубин, Кофейный Кварц*) и 5 светлых (*Нордический Лёд, Песочный Кашемир, Шалфей, Пудровый Кварц, Туманный Ирис*).
- **Родительский контроль:** защита каналов и категорий `18+` 4-значным PIN-кодом.
- **QR-Пульт для ТВ:** отправка длинных ссылок со смартфона по локальному Wi-Fi без мучений с экранной клавиатурой.
- **Резервная копия:** экспорт и импорт всех настроек в файл `CCTV-Plus-Backup.json` или через буфер обмена.
- **Безопасный автообновлятор:** проверка релизов прямо с GitHub с отображением шкалы загрузки в % и детектором «Обновлений нет».
- **Поддержка разработчика:** встроенное окно с реквизитами карты и криптовалют (USDT TRC20, TON, BTC).

## 🚀 Быстрый старт (Quick Start)

1. Установите **`CCTV-Plus.apk`** на смартфон или телевизор.
2. При первом запуске выберите удобный язык и тип устройства.
3. Перейдите в **Настройки ➔ 📡 Источники**:
   - На телефоне: добавьте ссылку M3U или выберите файл с устройства.
   - На телевизоре: откройте вкладку *«QR-загрузка»*, наведите камеру смартфона на экран и передайте все ссылки по Wi-Fi.
4. Приятного просмотра!

## 🛠 Технический стек (Tech Stack)

- **Язык:** Kotlin + Coroutines + Flow
- **Интерфейс:** Jetpack Compose (Material 3)
- **Видеоплеер:** AndroidX Media3 (ExoPlayer 1.5.0) + Jellyfin FFmpeg Audio Decoder
- **Сеть и парсинг:** OkHttp 4, XMLPullParser (потоковый парсер без OutOfMemory), GZIPInputStream
- **Графика и QR:** Coil Compose, Google ZXing
- **CI/CD:** GitHub Actions (автосборка релизов с постоянным криптографическим ключом `cctv_permanent.keystore`)
