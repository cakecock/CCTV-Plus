# 📺 CCTV Plus v2.0

Лёгкий (~8 МБ), быстрый и полностью бесплатный **IPTV и VOD плеер** без рекламы, аналитики и трекеров для **Android 10+ (смартфоны, планшеты и Android TV / ТВ-приставки)**.

> 📥 **[Скачать последнюю версию APK (GitHub Releases)](https://github.com/cakecock/CCTV-Plus/releases/latest/download/CCTV-Plus.apk)**

*(Примечание: если у вас стояла старая тестовая сборка, перед переходом на релиз с новой цифровой подписью сделайте экспорт настроек в `CCTV-Plus-Backup.json`, один раз удалите старое приложение и установите свежее — далее автообновления будут прилетать штатно.)*

## ✨ Основные возможности

### 🎬 Видеоплеер
- **3 движка на выбор:**
  - **ExoPlayer (Media3) + Jellyfin FFmpeg Decoder** — встроенное воспроизведение аудио **AC3 / EAC3 / DTS** без установки кодеков и внешних плееров.
  - **Системный (Android VideoView)**.
  - **Внешний плеер** (открытие потока в VLC, MX Player и др.).
- **Выбор качества видео** (`4K / 1080p / 720p / Авто`) для адаптивных HLS/DASH-потоков и VOD + отображение разрешения и FPS.
- **Выбор звуковой дорожки** и субтитров.
- **Архив передач (Catchup / Timeshift):** перемотка, выбор скорости (`1x–2x`), поддержка шаблонов `${start}`, `${end}`, `{start}/{end}`, `${start:yyyyMMddHHmmss}`, `${Y}/${m}/${d}` и Xtream `/timeshift/...`.
- **Мультиэкран (4×):** одновременный просмотр до 4 каналов на одном экране с переключением звука по тапу.
- **Живучесть потока:** умный авто-реконнект (3 попытки с паузой) + экран ошибки с кнопками «Повторить» и «Следующий канал», поддержка `User-Agent`, `Referer`, `Origin` и `Cookie` из M3U (`#EXTVLCOPT`).

### 📱 Смартфон и 📺 Android TV
- **Смартфон:**
  - Вертикальные свайпы яркости (слева) и громкости (справа) с автоматическим восстановлением яркости после выхода.
  - Двойной тап по краям экрана (`-10с / +10с`) на VOD и архивах.
  - Режим **картинка в картинке (PiP)** со скрытием оверлеев и авто-входом при нажатии Home.
  - Пауза при сворачивании, поддержка **Audio Focus** (пауза при звонке) и авто-пауза при отключении наушников.
- **Android TV / Пульт ДУ:**
  - Полная навигация **D-Pad** с яркой подсветкой фокуса, `Вверх/Вниз` для переключения каналов, ввод номера канала цифрами `0–9`, `OK / Влево` для открытия прозрачного **3-колоночного ТВ-Гида**, поддержка медиа-клавиш (`PLAY/PAUSE`, `NEXT`, `PREVIOUS`).
  - Отдельный широкий баннер **320×180** для ТВ-лаунчера и безопасные overscan-отступы.

### 📡 Источники, EPG и Удобство
- **M3U / M3U8:** потоковый парсер без перегрузки RAM на крупных плейлистах (ссылки и локальные файлы с флешки), локальный кэш на 2 часа.
- **VPortal** (`portal::[key:...]http://...`): навигация по категориям и сериалам, пагинация, серверный поиск, карточка фильма и **продолжение просмотра (Resume)** с сохранением прогресса.
- **Stalker Portal:** авторизация по MAC, загрузка жанров, ТВ-каналов и VOD-каталога через `create_link` с кэшированием токена.
- **EPG (XMLTV / `.xml.gz`):** автозагрузка из плейлиста, встроенные источники (TVLider / IPTVx) или свои ссылки, кэш 6 часов, фильтрация по каналам плейлиста для экономии памяти на 1 ГБ ТВ-боксах, сдвиг времени `-12..+12ч`.
- **Системные напоминания EPG:** сохраняются после перезапуска и присылают реальные Android-уведомления к началу передачи (клик открывает нужный канал).
- **QR-загрузка по Wi-Fi:** локальный веб-интерфейс для быстрой отправки **M3U, EPG, VPortal и Stalker (URL + MAC)** с телефона на телевизор. Работает только пока открыт экран QR и защищён одноразовым токеном.
- **Персонализация:** 10 цветовых тем (5 тёмных + 5 светлых), русский и английский интерфейсы, избранное со стабильными ID каналов, таймер сна, экспорт/импорт настроек в `.json`.

## 🔒 Безопасность и приватность
- Приложение **не содержит рекламы, аналитики и телеметрии** — все плейлисты и ключи хранятся только на вашем устройстве (`allowBackup="false"`, `dataExtractionRules`).
- **Родительский контроль (PIN):** PIN хранится в виде `PBKDF2`-хеша, есть защита от подбора, блокировка каналов «18+» и **любых выбранных вручную категорий** (🔒), запрос PIN на отключение защиты и автосброс разблокировки при сворачивании.
- Автоматическая маскировка ключей, паролей, токенов и MAC-адресов в диагностических логах и отчётах об ошибках.
- **Встроенное автообновление:** проверяет релизы на GitHub, сверяет **SHA-256** и **сертификат подписи APK** перед запуском установщика.

- **Язык и UI:** Kotlin, Coroutines, Jetpack Compose (Material 3)

- **CI/CD:** GitHub Actions (`compileSdk 35`, `minSdk 29`, `targetSdk 34`, R8 + ABI `arm64-v8a` / `armeabi-v7a`, подпись через GitHub Secrets)
