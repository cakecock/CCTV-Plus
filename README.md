# 📺 CCTV Plus — Smart IPTV & VOD Player

Современный, быстрый и удобный плеер для просмотра IPTV и онлайн-кинозалов на **Android TV**, ТВ-приставках и смартфонах (**Android 10+**).

## ✨ Основные возможности (Features)

- **📺 Всеядность форматов:**
  - Поддержка плейлистов **M3U / M3U8** (HLS, MPEG-TS, MP4, MKV).
  - Полная поддержка **VPortal** (`portal::[key:...]http://.../api/v1/` — например, от TVlider / iLook) для раздела «Кинозал (VOD)».
  - Поддержка **Stalker Portal / Ministra** с авторизацией по MAC-адресу.
- **🗂 Управление списками:**
  - Добавление нескольких плейлистов со своими названиями и быстрое переключение через выпадающее меню.
  - Автоматическая загрузка телепрограммы (**EPG**) прямо из плейлиста (`url-tvg` / `x-tvg-url`) + возможность добавлять несколько своих источников EPG (`.xml` и `.xml.gz`).
- **📱 Умный QR-Пульт для Android TV:**
  - Больше не нужно вводить длинные ссылки пультом от телевизора! Отсканируйте QR-код на экране ТВ камерой смартфона и отправьте ссылки на плейлисты, EPG и порталы за 5 секунд по домашнему Wi-Fi.
- **🎨 Персонализация и комфорт:**
  - **4 цветовые темы оформления:** 2 тёмные (*Графит и Изумруд*, *Королевский Аметист*) и 2 светлые (*Скандинавское Утро*, *Тёплый Латте*).
  - **2 языка интерфейса:** Русский 🇷🇺 и English 🇬🇧 (выбор при первом запуске и в настройках).
  - **Умный реконнект (Anti-Freeze):** автоматическое переподключение видеоплеера Media3 при кратковременных обрывах потока.
  - **Быстрый возврат (Recall):** переключение на предыдущий канал в один клик.
- **🔄 Автообновление из приложения:**
  - Встроенная проверка и установка свежих версий напрямую с GitHub в разделе *Настройки -> Вид и Язык*.

## 🚀 Быстрый старт (Quick Start)

1. Установите файл **CCTV Plus** на свой смартфон или телевизор Android TV.
2. При первом включении выберите язык интерфейса (**Русский** или **English**).
3. Перейдите во вкладку **Настройки**:
   - На **смартфоне**: добавьте свой плейлист во вкладке *«Плейлисты»* и портал во вкладке *«Порталы»*.
   - На **телевизоре**: откройте вкладку *«QR-Пульт»*, наведите камеру телефона на QR-код и вставьте все ссылки со смартфона.
4. Приятного просмотра!

## 🛠 Технический стек (Tech Stack)

- **Язык:** Kotlin + Coroutines
- **Интерфейс:** Jetpack Compose (Material 3)
- **Видеодвижок:** AndroidX Media3 (ExoPlayer + HLS + DASH)
- **Сборка и CI/CD:** GitHub Actions (автоматический выпуск релизов)
